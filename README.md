## 🇬🇧 English Version

ONE TASK is an innovative web application that acts as a personal productivity assistant. Instead of another overwhelming to-do list, the system guides the user through the "Golden Loop" – a proprietary 5-stage process that moves you from emotional blockage to taking the first, physical action step.

✨ Key Features

    🧠 The "Golden Loop": A 5-stage psychological process (Triage → Blockers → Warm-up → Bridge → Sprint).

    ⚡ Dual Mode System:

        🚑 Survival Mode: For bad days (zero pressure).

        🏆 Training Mode: For growth & building streaks.

    🎯 Smart Batching: Reduces AI operational costs by ~50%.


🏗️ Architecture & Tech Stack

    Frontend:
        - Vanilla JavaScript (ES6+) - Zero frameworks for maximum performance
        - CSS3 with Variables (Dark/Light mode support)
        - Responsive design, mobile-first approach

    Backend:
        - Python 3 + Flask (REST API)
        - Firebase Admin SDK (Authentication & Firestore)
        - JWT token-based security

    AI & Processing:
        - Google Gemini 2.5 Flash
        - Advanced prompt engineering
        - Custom "Smart Batching" algorithm

    Data Flow:
        -User Input → Flask API (JWT Auth) → AI Processing → Response → Frontend Update
